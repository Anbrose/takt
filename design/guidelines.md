# TAKT 设计准则

所有界面（iOS、网页）都按这份准则做。画布是设计的源头：
https://claude.ai/artifact/P9mddKiiDZTGZtrFjXPLpb

## 流程

- 任何 UI 改动先画到画布上，确认后再写代码。
- 代码里的界面以画布为准；两边不一致时改代码，或者先改画布再改代码。

## 动效

**所有过渡都是连续的。** 位置、大小、透明度、颜色都靠插值从旧状态走到新状态。缓动曲线可以改变加速度，但不能出现「一帧跳变」：某个东西在一帧之内突然出现、消失、换位置或换大小。

| 场景 | 做法 |
|---|---|
| 进入下一页 / 返回 | 推入：新页从右侧滑入，旧页向左移约 28% 并稍微变暗；返回时反向。例子：Project 列表 ↔ 规划页，进入子任务 ↔ 返回 |
| 元素出现 / 消失 | 淡入淡出，可以加一点位移或缩放（0.94–1） |
| 列表增删一项 | 高度从 0 展开 / 收起到 0，同时淡入 / 淡出，周围的项跟着平滑让位 |
| 排序变化 | 每一项从旧位置滑到新位置（FLIP） |
| 内容折叠 / 展开 | 高度连续变化，超出部分被裁剪，不允许溢出到容器外 |
| 弹层、底部栏 | 从屏幕边缘滑入滑出，背景遮罩同步淡入淡出 |
| 分段控件、标签页 | 高亮块滑动，内容整体平移 |
| 数字、短文字变化 | 数字滚动或交叉淡入 |
| 颜色、勾选、深浅色 | 渐变 |

**曲线和时长**
- 页面推入、弹层、展开收起：`cubic-bezier(0.32, 0.72, 0, 1)`（快出慢停），320–420ms。iOS 用对应的 spring 或 `.smooth`。
- 纯淡入淡出：`ease`，200–300ms。
- 动画进行中再次触发，要从当前状态接着走，不跳回起点。

**减少动态效果**：系统开启时去掉位移和缩放，改成短的淡入淡出。仍然不能一帧跳变。

**写代码时的检查**
- 每一处「条件显示」（SwiftUI 的 `if`、网页的条件渲染）都要有过渡；没有过渡就会一帧跳变。
- 被隐藏的元素既要视觉上隐藏，也要从辅助功能里隐藏。

## 文案

- 界面像一台机器：尽量少字。不放说明文字、状态词和计数，只显示关键的值（比如只写「1462 km」）。
- 按钮 1–4 个字，优先用图标加短词。
- 不要「问 AI」之类的输入组件。

## 视觉

- 主色 `#E6397C`（浅色模式）；深色模式底色 `#1A1A1D`。
- `#E6397C` 配白字或深色字对比度不足 4.5:1：
  - 原色只用于图形元素：路线、选中边框、标志、进度条。
  - 带文字的填充和粉色文字：浅色用 `#C2185B`（白字）；深色填充用 `#F272A3`（配 `#1A1A1D` 字），文字用 `#FF8AB5`。
- 完整色板见画布任一手机画板里的 `.t-light` / `.t-dark` CSS 变量；iOS 对应 `Theme.swift` 的 `Palette`。
- 字体：Inter + Noto Sans SC。
- 触控目标不小于 44px。
